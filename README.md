A Python program that draws a 1024×1024 newspaper front page summing up the world's news of Sunday 22 November 2026 in 12 stories — from the drone strike on the Russian cargo ship Sparta II in the Gulf of Finland, through missiles crashing in Poland and the COP31 overtime in Antalya, to sport and markets. Pure Pillow drawing: no network, no external assets, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
